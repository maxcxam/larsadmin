# 01. Setup
🇺🇦 [Українська](../01-setup.md)

How to install the panel and which commands it ships.

## Installation

Require the package with Composer and run the install command.

## Artisan commands

| Command | Creates |
| --- | --- |
| `larsadmin:entity` | an Entity |
| `larsadmin:action` | an action |
| `larsadmin:filter` | a filter |
| `larsadmin:metric` | a value, trend or partition metric |
| `larsadmin:dashboard` | a dashboard with cards |
| `larsadmin:tool` | a custom tool page |
| `larsadmin:field` | a custom field with its Vue component |
| `larsadmin:extension` | an extension package skeleton |

Run any command with `--help` to see its options.

## Configuration

The config file sets the path, the guard and whether the audit log is on.
