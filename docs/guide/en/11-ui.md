# 11. List interface
🇺🇦 [Українська](../11-ui.md) · 🌐 [larsadmin.dev](https://larsadmin.dev/en/docs/ui)

## Choosing columns

The list page and the relation panels have a **"Columns"** menu:

- show or hide a column;
- change the order with the ↑/↓ buttons;
- **"Reset"** restores the default columns (the order from `fields()`, without the `hideByDefault()`
  columns).

The choice is stored in the browser's `localStorage`, separately for each Entity, and is not sent to
the server.

| Where | `localStorage` key |
| --- | --- |
| Entity list | `larsadmin.columns.<uriKey>` |
| relation panel | `larsadmin.columns.<parent uriKey>.<field attribute>` |

Value format: `{ "order": [...], "hidden": [...] }`. If storage is unavailable (private mode), the
setting lasts until the page is reloaded.

The available columns are the fields visible on index ([Fields](03-fields.md)); `width()`, `align()`,
`wrap()`, `truncate()` and `hideByDefault()` set a column's initial properties.

## Responsiveness

- The table scrolls horizontally **inside its own container**, not the whole page.
- On mobile, the side navigation opens as a slide-out panel.
- The list toolbar (search, filters, columns, actions) adapts to the screen width.
- The content width is fluid: it takes up the available space.

## Row actions

Actions with `showInline()` are collected in the "⋯" menu of each row, next to the view, edit and
delete buttons. The menu shows only the actions available for that record. See
[Actions](07-actions.md#row-actions-and-detail-page-actions).

## Global search

The "Search…" button in the header (an icon on narrow screens) and the Ctrl+K hotkey (⌘K on macOS)
open the search palette over all Entities with `$globallySearchable`. ↑/↓ select a result, Enter opens
it, Ctrl/⌘+Enter, a middle click or Ctrl/⌘+click open it in a new tab, Esc closes the palette. The button only appears when the user
can reach at least one such Entity. See [Global search](16-search.md#interface-and-keyboard).

## Audit log

When the audit log is on and the user passes the `viewLarsadminAudit` gate, a "History" panel appears at
the bottom of the record page (10 entries, "Show more"), and the side menu gets an "Audit log" item: a
page of all changes with filters by section, event, user and date. See
[Audit log](17-audit-log.md#interface).

## Notifications

When notifications are on, a bell with the unread count appears in the header between search and the
user's name. It opens the list of notifications ("Show more", "Mark all as read", deleting single ones)
and a "Background tasks" section with progress and a "Cancel" button for background actions. New
notifications and finished background actions also pop up as toasts (up to three at once). The modal of
a background action says that it will run in the background. See
[Notifications and background actions](18-notifications.md#the-bell).
